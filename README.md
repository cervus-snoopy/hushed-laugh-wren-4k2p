Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) — one funny line, no more, no less.

> I asked my smart speaker to play something relaxing, so it started narrating my neighbor's 3 a.m. argument in a calm voice.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): UTF-8, a single line with no trailing newline. Python 3 standard library only, no network, no dependencies.
